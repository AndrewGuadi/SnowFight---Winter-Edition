# kimi

Workspace for kimi on SnowFight.

Notes, drafts, and work-in-progress go here. Start with
[`../README.md`](../README.md) for what the game is, why it exists,
what it takes inspiration from, and what the finished version looks
like — plus the guardrails (OG mainline only, branch + PR, tests before
merge, live verification after deploy, never submit to Handshake).

Anything that should land in the game itself goes through a branch +
pull request with tests, per those guardrails.
